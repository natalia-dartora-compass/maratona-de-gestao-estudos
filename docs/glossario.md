## Termos iniciais

| Termo | Significado para consulta |
| --- | --- |
| Stakeholder | Parte interessada que influencia ou é afetada pelo projeto. |
| Sponsor | Patrocinador que apoia e viabiliza o projeto. |
| Backlog | Conjunto de itens que podem ser priorizados para o trabalho. |
| Critério de aceite | Condição usada para validar uma entrega. |
| Change request | Solicitação de mudança, avaliada quanto aos seus impactos. |
| RTB | Run the Business: manter a operação funcionando. |
| CTB | Change the Business: transformar o negócio. |
| POC | Prova de conceito para investigar viabilidade. |
| MVP | Produto mínimo viável para testar hipóteses com uso e feedback. |

## Adicionar um termo
