> **Pergunta central:** quem influencia o projeto, quem decide e como todos acompanham o trabalho?

## Cargo e papel

Cargo é a posição na organização. Papel é o conjunto de responsabilidades e autoridade assumidas no contexto do projeto.

| Papel | Contribuição discutida |
| --- | --- |
| Sponsor | Viabiliza o projeto e apoia decisões estratégicas. |
| Gerente do projeto | Coordena o trabalho e integra as necessidades das partes interessadas. |
| Time | Realiza as entregas e contribui com conhecimento técnico. |
| Cliente e usuários | Expressam necessidades, usam e validam a solução. |
| PMO | Apoia padrões, práticas e governança. |

## Stakeholders

São pessoas ou grupos que influenciam ou são afetados pelo projeto. O time é apenas parte desse conjunto.

| Poder | Interesse | Como se relacionar |
| --- | --- | --- |
| Alto | Alto | Gerenciar de perto. |
| Alto | Baixo | Manter satisfeito. |
| Baixo | Alto | Manter informado. |
| Baixo | Baixo | Monitorar. |

Reavalie o mapa quando o contexto ou as responsabilidades mudarem.

## Princípios apresentados

1. Foco em valor.
2. Integrar sustentabilidade.
3. Adotar uma visão holística.
4. Incorporar qualidade.
5. Liderar com accountability.
6. Construir uma cultura de empoderamento.

_Complete cada princípio com uma definição, um exemplo e uma decisão que ele ajuda a orientar._

## Áreas de foco

| Área | Pergunta para estudar |
| --- | --- |
| Iniciação | Por que começar, com qual autorização e para quem? |
| Planejamento | O que fazer, com quais recursos, riscos e critérios de aceite? |
| Execução | Como realizar e validar as entregas? |
| Monitoramento e controle | Onde deveríamos estar, onde estamos e o que ajustar? |
| Encerramento | O que foi aceito, como fazer a transição e o que aprendemos? |

Essas áreas se relacionam e podem ocorrer de forma sobreposta. Não são uma sequência rígida que impede replanejamento.

_Mapeie aqui um sponsor, um usuário real e uma pessoa que pode decidir sobre uma mudança._
